# multi-tenant-soc-triage-framework
A structured, multi-layer identity &amp; threat triage playbook for SOC analysts.

## Framework Structure (Ordered)
1. Taxonomy - general outlines of common alerts
2. Heuristics - quick decision tree based on each alert type
3. Baselines - expected behavior from the environment
4. Tuning - logic for tuning out noisy alerts
5. Correlation Workflows
6. Workflow Guides
7. Outreach Templates
8. Incident Closure Library
9. Reference material
